04 Backend · C# · .NET

Fan–artist reservation system

A layered .NET 6 solution: an ASP.NET Core REST API with CRUD endpoints and analytics queries (best and worst fans, artist earnings), a generic repository over EF Core, a logic layer covered by NUnit and Moq tests, and SignalR notifications when artists change. A console client and a WPF desktop client consume the API.

Data is held in an EF Core in-memory database seeded with sample data. Created in 2023; WPF client added in 2026.
